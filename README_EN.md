# BeeCount Native Offline

An Android-only Kotlin / Compose / Room application, minimum API 26. Independent package and empty database; no migration from Flutter or the reference application. No network permission, AI runtime, ads, or subscription service.

See [implementation status](docs/NATIVE_IMPLEMENTATION.md) and [architecture](docs/NATIVE_DESIGN.md). Compilation and device execution are confined to the manually dispatched GitHub Actions workflow. A passing synthetic payment fixture is not a claim of compatibility with every real payment application.
