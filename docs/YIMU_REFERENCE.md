# 一木离线行为对比实验

本分支 `feat/yimu-reference-rebuild` 是独立的 Android 应用，最低 Android 8.0。它使用一木 6.3.0 中经过静态检查的界面资源、支付页面适配逻辑、分类权重和词典；本地业务由可读代码重新接线。它采用独立包名和数据库，与 BeeCount 其他分支的数据分开保存。

## 主要操作

- 首页可以切换账本，新增、编辑、删除和恢复账单。普通收支、转账、信用卡还款、借入借出及其后续结算都有实际保存入口。
- 支出详情可以记录退款、标记待报销和登记报销回款。信用账户详情可以查看账期，并为消费账单添加、修改或移除分期安排；分期不会再次扣除已发生的本金。
- 自动记账设置中开启总开关，按页面指引授予无障碍和悬浮窗权限，勾选要读取的应用，并选择目标账本。支付详情可生成浮窗或待确认记录，确认后写入账本。同页重绘不会反复抢焦点弹窗，订单号等强身份用于去重，证据不足的记录保留人工确认。
- 预算支持选择历史月份、设置父类或子类预算，以及指定起止日期的自定义预算。预算内可以查看实际计入的账单；标记“不计预算”的记录不计入。
- 投资持仓可手工登记买入、卖出、分红与价格，查看份额、成本和盈亏。持仓日志独立于现金账户；录入投资事件不自动制造现金收支，也不重复加入账户净资产。行情接口未接入。
- 存钱目标可维护手工进度，也可依据选择的账户或账本收支计算进度。周期规则可指定间隔、结束日期或总次数，到期生成待确认记录；系统省电策略可能延迟后台处理。
- 数据页面提供 CSV 导入导出和完整 ZIP 备份恢复。CSV 用于迁移账单，ZIP 同时保存全部账本、财务关联、规则、目标和附件。导入校验失败时整体回滚。
- 本地自动备份需要选择文件夹并授予持久读写权限；可以立即备份、恢复历史文件，并保留最近 7、14 或 30 份。系统在电量和空间允许时执行每日任务，只清理本功能生成的备份。
- 应用锁使用 Android 的生物识别或设备凭据，切到后台后重新锁定。

## 对比范围

应用没有 INTERNET 权限，不接入同步、广告、在线行情、会员购买或授权服务，不加载原 APK、SO、序列化对象或动态 DEX。恢复的模型和词典仅按固定格式读取数值和文字；自动分类的分词采用近似实现，分类建议可以手动修改。

这一版优先完成主要离线操作。原版手势锁、部分高级显示设置、预算自动滚存和某些特殊周期规则尚未逐项复刻；像素和工具函数实现顺序也不作为当前交付标准。普通外币账本可以记录收支，原版转账、借贷和分期流程目前主要面向人民币账户。

云端模拟器使用本项目自有支付窗口检查采集、浮窗和账务回归。它不能证明 22 个真实支付应用的所有版本和不同手机系统均兼容。没有运行原版 APK，因此不声称已完成原版动态或像素对比。

## 构建与验证

使用仓库的手动 `release.yml` 长流水线，一次完成编译、已有单元和设备检查、权限与载荷审查、签名检查及界面截图。当前功能批次不增加测试用例，已有数据库版本断言随格式升级更新。提交前先集中静态交叉审查，再消耗一次云端编译；不为几行修改单独触发流水线。

完整备份格式为 schema 11，包含 37 张表，并保留恢复旧实验版 v1–v10 备份的路径。它不是原版一木的备份格式。
