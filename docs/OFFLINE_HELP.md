# 蜜蜂记账 · 离线版

本版本由 wcwac 基于 sunxiao（TNT-Likely）的 BeeCount 修改，保留原项目版权和许可证。

## 日常使用

- 使用底部导航查看明细、统计、账户和设置。
- 点击“记账”新增收入、支出或转账。
- 点击首页账本名称切换账本，通过“管理账本”创建、编辑或删除账本。
- 在账本操作菜单中管理预算。周期交易和记账提醒位于设置的“自动化”中。
- 图片附件由你主动拍照或选择文件添加，不会自动监听相册或截图。

## 财务管理与日历

- 从“资产 → 财务管理”管理报销、借入借出、分期、房贷及理财。
- 报销支持关联已有支出、部分回款；借还款分别记录本金和利息。
- 分期和房贷支持固定利率的等额本息、等额本金还款表、逐期还款与提前结清。
- 理财支持手动买入、卖出份额、现金分红和市值更新，计算加权成本与盈亏。
- 本金往来不重复计入收支及预算，利息和已实现收益按收入或支出统计。
- 已有业务只登记余额时，关闭创建表单的资金流水开关；避免重复扣款或到账。
- 专用账户和关联流水通过财务管理纠错，可以撤销最后一笔或删除整条记录。
- “充值账户”适合公交卡、饭卡：充值走转账，消费走支出。
- 点击首页右上角日历图标，查看每日收支及当天流水。

## 数据与备份

账目保存在本机。应用不提供云同步、共享账本、AI 识别、在线汇率或应用内更新。

请定期在“数据管理”中导出完整数据库 JSON 备份（“备份全部账务数据”，附件另行导出），并自行复制到安全位置。卸载应用或清除应用数据会删除本地账目；系统云备份也已关闭。恢复备份前，请先备份当前数据。

CSV 用于流水交换，YAML 用于配置，两者不能代替包含财务计划与关联关系的完整 JSON 备份。完整备份恢复会覆盖现有本地数据库，不含应用偏好或附件图片。

本版本与原版使用不同的 Android 应用 ID。首次迁移需要从原版导出数据，再在本版本导入。请核对笔数、账户余额和附件后再处理原版数据。

## 多币种

外币交易使用本地保存或手动输入的汇率。更改账本本位币后，请检查相关交易的折算金额；应用不会联网获取最新汇率。

## 外观与安全

可以调整明暗主题、主题色和字号，并开启应用锁。提醒是否按时显示还取决于系统通知和电池设置。

## 更新与许可

更新包由自己的 GitHub 仓库 Actions 构建。安装更新时必须使用同一应用 ID 和签名密钥。

项目基于 BeeCount，原项目地址为 https://github.com/TNT-Likely/BeeCount 。许可证详情见“关于”中的许可证。
