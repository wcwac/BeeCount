# 蜜蜂记账 · 离线版

本版本由 wcwac 基于 sunxiao（TNT-Likely）的 BeeCount 修改，保留原项目版权和许可证。

## 日常使用

- 使用底部导航查看明细、统计、账户和设置。
- 点击“记账”新增收入、支出或转账。
- 点击首页账本名称切换账本，通过“管理账本”创建、编辑或删除账本。
- 在账本操作菜单中管理预算。周期交易和记账提醒位于设置的“自动化”中。
- 图片附件由你主动拍照或选择文件添加，不会自动监听相册或截图。

## 数据与备份

账目保存在本机。应用不提供云同步、共享账本、AI 识别、在线汇率或应用内更新。

请定期在“数据管理”中导出备份，并自行复制到安全位置。卸载应用或清除应用数据会删除本地账目；系统云备份也已关闭。恢复备份前，请先备份当前数据。

本版本与原版使用不同的 Android 应用 ID。首次迁移需要从原版导出数据，再在本版本导入。请核对笔数、账户余额和附件后再处理原版数据。

## 多币种

外币交易使用本地保存或手动输入的汇率。更改账本本位币后，请检查相关交易的折算金额；应用不会联网获取最新汇率。

## 外观与安全

可以调整明暗主题、主题色和字号，并开启应用锁。提醒是否按时显示还取决于系统通知和电池设置。

## 更新与许可

更新包由自己的 GitHub 仓库 Actions 构建。安装更新时必须使用同一应用 ID 和签名密钥。

项目基于 BeeCount，原项目地址为 https://github.com/TNT-Likely/BeeCount 。许可证详情见“关于”中的许可证。
